# Citation and License

Sources:

- NVD CVE JSON 2.0 data feeds: https://nvd.nist.gov/vuln/data-feeds
- CISA Known Exploited Vulnerabilities Catalog: https://www.cisa.gov/known-exploited-vulnerabilities-catalog
- FIRST EPSS current scores: https://www.first.org/epss/data_stats.html

This Kaggle package is a convenience snapshot built from official U.S. government cybersecurity sources plus FIRST EPSS scores. It does not assert that non-KEV CVEs are unexploited; it only marks CVEs that appear in CISA KEV at build time. EPSS is a current probabilistic score and can change as the FIRST model and source data update.

For operational vulnerability management, verify the live NVD, CISA, and FIRST EPSS source records before making patching or risk decisions.
